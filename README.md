# Secure Traffic Crash Web Application

A Dockerized PHP/MySQL web application for exploring and querying traffic crash data. This project is being extended as a case study in **secure web application development, backend security, and secure deployment**.

## Project Background

The original Traffic Crash Web Application was developed as a team project for a database course.

The project is now being independently extended to explore cybersecurity concepts and secure software development practices.

## Technology Stack

- PHP
- MySQL
- Apache
- Docker / Docker Compose
- Linux Home Server
- Git / GitHub

## Current Development

The application has been migrated from a local development environment to a Docker-based deployment on a self-hosted Linux server.

Current development focuses on reviewing the existing application and identifying opportunities to improve its security and deployment architecture.

## Project Goals

The goal of this project is to explore how secure software development principles can be applied to an existing web application while maintaining its original functionality.

Future development may include security testing, regression testing, and a redesigned backend using Python and FastAPI.

## Status

**Active Development**

Security analysis and improvements are currently in progress.
